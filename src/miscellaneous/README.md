# Archived Experiments

This directory contains experimental architectures and training approaches
explored during development but not used by the final submitted model.

They are retained to show the development process and to keep older checkpoints
loadable. The supported final implementation and commands are documented in the
repository root README.

Archived work includes Hybrid V1, V2, and V3; progressive deeper EfficientNet
fine-tuning; and the original random-distortion generator.
